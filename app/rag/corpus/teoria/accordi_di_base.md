# Accordi di base

## Come è fatto un accordo
Un accordo **maggiore** è fatto da fondamentale, terza maggiore (4 semitoni sopra) e quinta (7 semitoni sopra): suono "allegro", aperto. Un accordo **minore** ha la terza minore (3 semitoni): suono "triste", scuro. Nella sigla: `C` = Do maggiore, `Am` = La minore, `G7` = Sol di settima (aggiunge la settima minore).

## Accordi aperti (prima posizione)
Usano corde a vuoto e i primi tre tasti. Dalla 6ª alla 1ª corda (`x` = corda non suonata):
| Accordo | Tasti |
|---|---|
| C (Do) | x 3 2 0 1 0 |
| A (La) | x 0 2 2 2 0 |
| Am (La minore) | x 0 2 2 1 0 |
| G (Sol) | 3 2 0 0 0 3 |
| E (Mi) | 0 2 2 1 0 0 |
| Em (Mi minore) | 0 2 2 0 0 0 |
| D (Re) | x x 0 2 3 2 |
| Dm (Re minore) | x x 0 2 3 1 |

## Barrè (barré, barre): cos'è
Il barrè (scritto anche barré o barre) è la tecnica, e l'accordo, in cui l'indice preme tutte le corde sullo stesso tasto e le altre dita formano una delle forme aperte spostata in alto. Forma "di Mi" con fondamentale sulla 6ª corda (es. F = 1 3 3 2 1 1) e forma "di La" con fondamentale sulla 5ª (es. B = x 2 4 4 4 2). Spostando la stessa forma lungo il manico si ottengono tutti gli accordi maggiori e minori.

## Arpeggio
Suonare un accordo **una nota alla volta** invece che tutte insieme si chiama arpeggio. Nelle tablature appare come numeri in sequenza che, insieme, formano la forma di un accordo (es. l'intro di molte ballate rock).

## Consiglio
Quando nella tab compaiono numeri in colonna che non riconosci, prova a cercare la forma di un accordo noto spostata lungo il manico: spesso è un barrè o un accordo aperto suonato in un'altra posizione.
